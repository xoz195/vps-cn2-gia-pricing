**多站点、中等流量**：CN2 GIA-E 80G（4GB/3TB，$56.99/月）或160G（8GB/5TB，$86.99/月）。到这一档带宽也从2.5Gbps升到5Gbps，晚高峰扛得住。

**华南用户、对延迟极敏感**：直接上香港或东京CN2 GIA，2GB起步$89.99/月。延迟比洛杉矶低100ms，但价格也贵了4倍多，而且流量只有500GB。如果预算紧但想要亚太低延迟，大阪和新加坡的$49.99/月（2GB/500GB）是更划算的折中方案。

**企业级、高流量**：CN2 GIA-E 320G以上或香港/东京的高配套餐。这些套餐带宽到10Gbps、流量到8-20TB，适合做CDN源站、大流量站点或多人共用环境。

## 七、几个常见疑问

**CN2 GIA-E和CN2 GIA有什么区别？**
在搬瓦工体系里，CN2 GIA-E（E-Commerce）是洛杉矶DC6的线路，CN2 GIA是DC9的线路。两者都是电信AS4809的CN2 GIA网络，DC9额外整合了移动CMIN2和联通Premium，三网表现更均衡。购买CN2 GIA-E套餐后可以在后台免费迁移到DC9，所以实际不用太纠结买哪个。

**限量版和常规版能用一样的机房吗？**
不完全一样。限量版可选机房范围比常规版窄，通常限定在DC6/DC9等少数几个CN2 GIA-E机房，不能迁移到香港、东京等Ultra机房。常规版CN2 GIA-E套餐可以迁移的机房更多。

**搬瓦工的CN2 GIA美国VPS稳定吗？**
搬瓦工做CN2 GIA美国VPS已经很多年，是这类产品里口碑最稳定的商家之一。官方提供99.9% SLA（部分套餐），30天退款，KiwiVM面板支持快照、机房迁移、rDNS等。需要注意CN2 GIA网络容量有限，官方明确说不抗DDoS，遇到攻击会直接nullroute IP，如果你的业务容易招攻击，这点要考虑进去。

**能用支付宝付款吗？**
可以。搬瓦工支持支付宝、PayPal、信用卡，国内用户用支付宝最方便。
